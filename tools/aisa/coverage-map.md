# AIsa Marketing Data Coverage

> **◆ Verified Partner integration.** AIsa sponsors Marketing Skills. This integration is disclosed and vetted for fit; it does **not** change what any skill recommends. It's listed alongside the neutral options for the same job — use it when it's the right fit, not because it's a partner. See [Verified Partners](../REGISTRY.md#verified-partners).

This map connects specific marketing data needs to AIsa's documented capabilities. A row means a possible source for part of a workflow, not full support for the linked skill. The skill supplies the method; the agent chooses a data source based on the user's existing accounts, required fields, coverage, and budget.

## Evidence and Scope

**Documentation snapshot: 2026-10-15.** The linked official provider pages and public [MCP catalogue](https://mcp.aisa.one/servers) / [MCP guide](https://mcp.aisa.one/llms.txt) describe these capability families. No authenticated provider calls were run for this map, so runtime availability, returned fields, data quality, and settled costs remain unverified.

The public API pages label their contracts **Declared**. Connect through `https://mcp.aisa.one/mcp`, discover the exact operation, inspect its current schema, access requirements and price, and follow the [quick start](README.md) before execution. Do not derive an operation ID or request body from a provider name in this table.

## Boundaries and Provider Selection

- **Use existing access when it fits.** A direct provider account or user-supplied export may already contain the necessary data. Compare current coverage and total workflow cost before adding another paid route.
- **No coverage claim for unlisted workflows.** This map does not establish support for private analytics, ad-account reporting, email campaign management, CRM synchronization, publishing, or experiment execution. Verify those independently. [Composio](../integrations/composio.md), a provider's native integration, or the repository's [CLI tools](../REGISTRY.md) may fit an authenticated account workflow.
- **Keep reads and actions separate.** The existence of Apollo or social APIs does not authorize contact creation, sending, posting, or engagement. Inspect the selected operation's side effects and account boundary.
- **Preserve missing data.** If access, schema, or coverage is insufficient, identify the gap and use an available alternative. Do not silently substitute one provider's metric for another or fabricate values.
- **Maintain the snapshot.** When refreshing this map, recheck its sources and MCP discovery results, then update the date and affected [evals](evals/README.md). Keep any execution evidence separate from documentation checks.
