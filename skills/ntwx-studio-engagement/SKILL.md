# NTWX Studio Engagement (Categories 02–11)

**Catalogue:** https://aaas.ml-nightworx.io  
**Context:** Run `ntwx-product-marketing` + `ntwx-block0-discovery` first

## Positioning frame

Lead with: **pilot → enterprise-scale governed agents** — not generic AI consultancy.

Use positioning statement from `templates/product-marketing-studio.md`.

## Workflow

### 1 — Category match

Read `references/ntwx/eleven-categories.md`. Identify:
- Category number and name
- Example offers / live surface
- Indicative band (reference only)
- Lead archetype for delivery handoff

### 2 — Block 0

Run `ntwx-block0-discovery`. Do not quote fixed price without completed Block 0.

### 3 — Gap audit (Phase 3 equivalent)

Pre-filled draft vs public live demo in category:

1. Technical gap + commercial impact  
2. Governance gap (authority limits, model-spend) + risk  
3. Deployability gap (pilot stuck vs production path)  

Ask prospect to confirm or correct — same psychology as Reflector Phase 3.

### 4 — Decision-maker one-pager

Structure:

- **THE OPPORTUNITY** — Block 0 primary outcome  
- **WHAT WE FOUND** — 3 audit findings  
- **WHY ML-NIGHTWORX** — governed deploy + pattern library + Cloudflare production  
- **SCOPE SHAPE** — productised pattern + custom last mile (integrations, UX, authority)  
- **INDICATIVE INVESTMENT** — band from catalogue + Block 0 disclaimer  
- **NEXT STEP** — Block 0 workshop or 15-min scope call  

**Sequencing:** No live demo deep-dive until gap acknowledged.

### 5 — Solution demo

Show **live surface** from category (aaas link) — 10 min max. Map to their magic-wand / Block 0 outcome.

Delegate demo script structure to upstream `sales-enablement`; enforce governance narrative.

### 6 — Proposal / close

Fixed-scope doc:
- Block 0 summary
- Deliverables (pattern + last mile)
- Authority limits & security constraints
- Timeline milestones
- Managed ops option (ERIS retention lane)

**Commander HALT** before sending formal quote.

## Pricing disclaimer (mandatory)

> Price ranges are indicative estimates for comparable scopes. Exact pricing depends on the Block 0 brief, integration requirements, agent authority limits, and security/firewall constraints.

## Porter check

Confirm segment narrow enough per `references/ntwx/porter-differentiation-focus.md`. If prospect is really Cat 01 Reflector fit → hand off to `ntwx-reflector-sales`.

- `ntwx-block0-discovery`, `ntwx-compatibility-score`, `ntwx-product-marketing`
- Upstream: `offers`, `pricing` (Commander HALT), `copywriting`, `sales-enablement`
