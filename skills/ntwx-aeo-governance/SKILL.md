# NTWX AEO & Governance (Public Surfaces)

**Moat layer:** Reflector #7 GEO/AEO schema; aaas delivery model AI-search readiness  
**Review:** PETA for security/authority claims on public docs

## NTWX requirements (every live surface)

1. Root `/llms.txt` — concise agent discovery  
2. `/llms-full.txt` where catalogue depth warrants it  
3. JSON-LD / structured data for key entities (org, product, FAQ)  
4. Clear demo vs production disclaimers where applicable  
5. No overclaiming live status — align with aaas framing  
6. Governance vocabulary where relevant (authority limits, not hype)

## Workflow

### 1 — Audit

Delegate technical audit to upstream `seo-audit` + `ai-seo`. Add NTWX checklist:

- [ ] llms.txt present and current  
- [ ] Pricing language matches indicative/disclaimer rules  
- [ ] Category catalogue matches `eleven-categories.md`  
- [ ] Contact/onboarding paths clear  
- [ ] No leaked internal-only URLs (Reflector sales OS is internal)

### 2 — Schema

Delegate implementation patterns to upstream `schema`. NTWX entities:

- Organization: ML-NIGHTWORX  
- WebSite / WebPage for aaas categories  
- SoftwareApplication for productised offers (Reflector, InfraDOME, etc.)

### 3 — Copy for agent consumption

Structure for LLM crawlers:

- One-line positioning  
- 11 category index with indicative bands + disclaimer  
- Delivery model bullets (strategy, agents, platform, UX, AEO, governed deploy)  
- Block 0 dependency for exact pricing

### 4 — PETA review trigger

HALT public publish if claims include:

- Specific client names without approval  
- Defence/classified implications (Cat 08)  
- Trading return guarantees (Cat 06)  
- "Production" for pattern/demo without Commander sign-off
